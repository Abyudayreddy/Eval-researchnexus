## 1. Primary Research Question & Controlled Experimental Protocol

**Does the ResearchNexus Enhanced RAG pipeline improve scientific answer quality, evidence grounding, and citation correctness compared with a conventional RAG generation pipeline using identical retrieved evidence?**

### Baselines Compared

- **B5R (Conventional RAG)**: Question $\rightarrow$ Frozen B4 Evidence $\rightarrow$ Direct conventional context concatenation $\rightarrow$ Gemini 2.5 Flash generation $\rightarrow$ Conventional citation parsing.
- **B5E (Enhanced RAG)**: Question $\rightarrow$ Frozen B4 Evidence $\rightarrow$ Phase 3.3 Evidence-first pipeline (Eligibility validation $\rightarrow$ bounded evidence use $\rightarrow$ evidence deduplication $\rightarrow$ structured context construction $\rightarrow$ citation mapping $\rightarrow$ Gemini 2.5 Flash generation $\rightarrow$ structural citation validation $\rightarrow$ evidence manifest).

### Absolute Controlled Experimental Locks

- Identical frozen TEST split items ($N=15$).
- Identical question prompts, gold paper annotations, and gold evidence chunk references.
- Identical immutable retrieved evidence set generated by canonical B4.
- Identical generation model: **Gemini 2.5 Flash** ($temp=0.0$, $max\_tokens=1024$).
- Identical refinement mode: `refinement_mode = "single_pass"` (no Phase 3.5 iterative refinement).
- No Phase 3.4 Claim Verification as input/intervention for either system (evaluated separately in E04).

## 11. Final Measured Scoped Conclusion

> ### **Conclusion**: **`QUALITY IMPROVEMENT WITH LATENCY TRADEOFF`**
> 
> On ResearchNexus Scientific Retrieval Benchmark v1.0 TEST split ($N=15$), **B5E Enhanced RAG produced Citation Precision = 0.947 compared with 0.733 for B5R Conventional RAG** ($\Delta = +0.214$, Wilcoxon $p = 0.0120$), and reduced the Unsupported Claim Rate from $0.160$ to $0.040$ ($\Delta = -0.120$, a $75.0\%$ reduction in ungrounded claims). 
> 
> This quality enhancement incurs a predictable latency cost of **$+50.6\text{ ms}$ P50 latency overhead** ($383.0\text{ ms} \rightarrow 433.6\text{ ms}$) and 1 additional structural validation model call ($2$ calls vs $1$ call). Because B5E produced zero quality degradations ($0$ degradation cases) and significantly improved evidence grounding, Enhanced RAG is recommended for scientific writing applications where citation correctness and evidence fidelity are paramount.
