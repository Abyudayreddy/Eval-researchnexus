# Diagnostic Forensic Audit: Retrieval Sanity Checks

## 1. Overview & Method

To diagnose why Module 1 retrieval evaluations yielded near-zero Hit@5 metrics across `ds_nexus_v10`, 5 representative benchmark queries with non-empty gold targets were selected for manual candidate pool inspection.

For each query, BM25, Dense vector, and Hybrid RRF candidate lists ($K=10$) were inspected for the presence of the exact gold target paper ID.

## 3. Diagnostic Summary

- **Gold Paper ID Match**: Identifiers match 100% identically with the corpus (`local:Artificial_Intelligence:...`).
- **Gold-in-Candidate Status**: **NO** for all 5 queries.
- **Root Diagnostic Cause**: The benchmark question text generated by `seed_benchmark_v10.py` consisted of generic template strings ("What is the primary contribution reported in paper X regarding neural architecture design?") that bear zero lexical or embedding similarity to the actual scientific text contents of paper X.
- **Conclusion**: The near-zero retrieval scores are caused by **synthetic query-corpus semantic mismatch (CASE F)**, NOT by index ID corruption or metric calculation errors.
